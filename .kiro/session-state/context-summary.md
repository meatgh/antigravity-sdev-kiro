## December 31, 2025 Session Update - OOP FUNDAMENTALS ENHANCEMENT CONTINUATION

### CONTEXT CONSOLIDATION FROM TEMPORARY.MD

**L - Liskov Substitution Principle**:
Subtypes must be substitutable for their base types.

**I - Interface Segregation Principle**:
Clients shouldn't depend on interfaces they don't use.

```java
// Bad - Fat interface
interface Worker {
    void work();
    void eat();
    void sleep();
}

// Good - Segregated interfaces
interface Workable {
    void work();
}

interface Eatable {
    void eat();
}

interface Sleepable {
    void sleep();
}

class Human implements Workable, Eatable, Sleepable {
    public void work() { /* human work */ }
    public void eat() { /* human eat */ }
    public void sleep() { /* human sleep */ }
}

class Robot implements Workable {
    public void work() { /* robot work */ }
    // Robot doesn't need to eat or sleep
}
```

**D - Dependency Inversion Principle**:
Depend on abstractions, not concretions.

```java
// Bad - High-level module depends on low-level module
class EmailService {
    public void sendEmail(String message) { /* send email */ }
}

class NotificationManager {
    private EmailService emailService = new EmailService(); // Tight coupling
    
    public void sendNotification(String message) {
        emailService.sendEmail(message);
    }
}

// Good - Depend on abstraction
interface NotificationService {
    void send(String message);
}

class EmailService implements NotificationService {
    public void send(String message) { /* send email */ }
}

class SMSService implements NotificationService {
    public void send(String message) { /* send SMS */ }
}

class NotificationManager {
    private NotificationService service; // Depends on abstraction
    
    public NotificationManager(NotificationService service) {
        this.service = service;
    }
    
    public void sendNotification(String message) {
        service.send(message);
    }
}
```

#### Q20: Design a comprehensive file system using OOP principles
**Companies**: Google, Amazon, Microsoft  
**Difficulty**: Hard  
**Category**: System Design

**Question**: Design a file system that supports files, directories, permissions, and operations like create, delete, move, copy. Include features like file search, size calculation, and permission management.

**Brute Force Approach**:
```java
// Bad approach - everything in one class
public class FileSystem {
    private Map<String, Object> items; // Mixed files and directories
    
    public void createFile(String path, String content) {
        // Hundreds of lines mixing file creation, path parsing, permission checking
    }
    
    public void createDirectory(String path) {
        // More mixed logic without proper abstraction
    }
    
    public long getSize(String path) {
        // Complex recursive logic without proper OOP structure
    }
}
```

**Optimal Solution - Proper OOP Design**:

```java
// Abstract base class for all file system items
public abstract class FileSystemItem {
    protected final String name;
    protected final String path;
    protected final LocalDateTime createdAt;
    protected LocalDateTime modifiedAt;
    protected final String owner;
    protected final Set<Permission> permissions;
    protected FileSystemItem parent;
    
    protected FileSystemItem(String name, String path, String owner) {
        this.name = validateName(name);
        this.path = validatePath(path);
        this.owner = validateOwner(owner);
        this.createdAt = LocalDateTime.now();
        this.modifiedAt = LocalDateTime.now();
        this.permissions = EnumSet.of(Permission.READ, Permission.WRITE);
        this.parent = null;
    }
    
    // Template method for size calculation
    public abstract long getSize();
    
    // Template method for deletion
    public final boolean delete(String user) {
        if (!hasPermission(user, Permission.WRITE)) {
            throw new SecurityException("No write permission for user: " + user);
        }
        
        if (!canDelete()) {
            return false;
        }
        
        boolean result = performDelete();
        
        if (result && parent != null) {
            parent.removeChild(this);
            parent.updateModifiedTime();
        }
        
        return result;
    }
    
    protected abstract boolean canDelete();
    protected abstract boolean performDelete();
    protected abstract void removeChild(FileSystemItem child);
    
    public boolean hasPermission(String user, Permission permission) {
        if (owner.equals(user)) {
            return true; // Owner has all permissions
        }
        
        return permissions.contains(permission);
    }
    
    public void addPermission(String user, Permission permission) {
        if (!owner.equals(user)) {
            throw new SecurityException("Only owner can modify permissions");
        }
        permissions.add(permission);
    }
    
    public void removePermission(String user, Permission permission) {
        if (!owner.equals(user)) {
            throw new SecurityException("Only owner can modify permissions");
        }
        permissions.remove(permission);
    }
    
    protected void updateModifiedTime() {
        this.modifiedAt = LocalDateTime.now();
        if (parent != null) {
            parent.updateModifiedTime();
        }
    }
    
    // Validation methods
    private String validateName(String name) {
        if (name == null || name.trim().isEmpty()) {
            throw new IllegalArgumentException("Name cannot be null or empty");
        }
        if (name.contains("/") || name.contains("\\")) {
            throw new IllegalArgumentException("Name cannot contain path separators");
        }
        return name.trim();
    }
    
    private String validatePath(String path) {
        if (path == null || !path.startsWith("/")) {
            throw new IllegalArgumentException("Path must start with /");
        }
        return path;
    }
    
    private String validateOwner(String owner) {
        if (owner == null || owner.trim().isEmpty()) {
            throw new IllegalArgumentException("Owner cannot be null or empty");
        }
        return owner.trim();
    }
    
    // Getters
    public String getName() { return name; }
    public String getPath() { return path; }
    public LocalDateTime getCreatedAt() { return createdAt; }
    public LocalDateTime getModifiedAt() { return modifiedAt; }
    public String getOwner() { return owner; }
    public Set<Permission> getPermissions() { return EnumSet.copyOf(permissions); }
    public FileSystemItem getParent() { return parent; }
    
    public void setParent(FileSystemItem parent) {
        this.parent = parent;
    }
    
    @Override
    public boolean equals(Object obj) {
        if (this == obj) return true;
        if (!(obj instanceof FileSystemItem)) return false;
        FileSystemItem other = (FileSystemItem) obj;
        return Objects.equals(path, other.path);
    }
    
    @Override
    public int hashCode() {
        return Objects.hash(path);
    }
    
    @Override
    public String toString() {
        return String.format("%s{name='%s', path='%s', owner='%s', size=%d}", 
            getClass().getSimpleName(), name, path, owner, getSize());
    }
}
```
